# 17: 调试图像模板

**What to build:** 调试工作区支持原生节点与图像模板定位，冻结后可框选并保存模板版本，重新匹配显示真实结果，模板库跨会话共享，任务执行锁定版本。

**Blocked by:** 01、02

**Status:** ready-for-agent

- [ ] AC-DBG-01：冻结视图、节点、裁剪和结果对应同一快照
- [ ] AC-DBG-02：会话失效或快照淘汰时不提交旧坐标，不留下活动占用
- [ ] AC-DBG-03：resource-id 优先，表达式可复制且结果与图像一致
- [ ] AC-DBG-04：未冻结或忙设备禁止框选；4×4、越界、非整数拒绝；预览与覆盖层同映射；尺寸不兼容清除选区
- [ ] AC-DBG-05：同名未确认冲突，确认后追加版本；阈值 0.10–1.00；匹配失败不伪造；模板库跨会话；执行锁定 version 与 sha256
