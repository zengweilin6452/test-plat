# 05: 受控来源与固定代码副本

**What to build:** 从预配置来源登记套件，服务端保存 V1 代码副本与摘要；发现和执行都读副本，来源更新产生新版本。

**Blocked by:** 01、03

**Status:** ready-for-agent

- [ ] AC-INPUT-02：旧版本在来源目录变化后仍使用 V1
- [ ] 浏览器不能传任意宿主路径；越界与符号链接逃逸拒绝
- [ ] 原件损坏或缺失阻断，不回退到可变来源目录
- [ ] 磁盘不足返回明确错误，不自动淘汰旧副本
- [ ] 旧 suite 无副本时标记“未保留固定代码”，新运行前须显式创建新版本
