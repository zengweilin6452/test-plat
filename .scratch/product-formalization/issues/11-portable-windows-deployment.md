# 11: 可迁移的 Windows 部署与启停

**What to build:** 用户能够在另一 Windows 安装目录和指定端口启动平台，配置不依赖开发者个人机器，启停和健康检查指向同一实例。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

**规格依据：** TestDock 正式化改造规格（2026-11-03）；AC-13、AC-16。遵守已确认的单工作空间边界及稳定身份、可恢复归档决策。

## Acceptance criteria

- [ ] 数据库、产物、运行时、Python、ADB 和可信来源沿用统一配置机制，路径基于配置或安装目录，不依赖个人绝对路径。
- [ ] 启动、前端代理、健康检查及停止使用相同端口设置；支持覆盖默认值，端口占用明确报错，不把陌生服务的 200 响应当成平台就绪。
- [ ] 验证含空格目录和解释器路径，停止只作用于本次识别的实例；后台进程按 Windows 约定隐藏启动。
- [ ] 正常运行直接使用既有 vendor 快照；开发者同步通过显式源配置，不依赖个人仓库路径，保持源码只读。
- [ ] 提供无秘密的配置示例、Windows 部署升级和备份恢复说明；公开页面不暴露凭证、令牌或敏感宿主配置。
- [ ] 在隔离目录验证默认及覆盖配置、端口冲突、启停和现有数据升级；不安装新依赖或引入新来源，不接触用户已有服务。
