# 01: 工作空间设置与真实品牌信息

**What to build:** 用户可以修改当前工作空间名称，侧栏、面包屑和刷新后的页面始终显示同一值；品牌、工作空间和本机使用模式各自表达真实含义。

**Blocked by:** None (can start immediately)

**Status:** resolved

**规格依据：** TestDock 正式化改造规格（2026-11-03）；AC-02、AC-14。遵守已确认的单工作空间边界及稳定身份、可恢复归档决策。

## Acceptance criteria

- [ ] 工作空间设置由服务端持久化，默认名称为“默认工作空间”；不建立租户或工作空间切换器。
- [ ] 名称去除首尾空白并校验 1–60 字符；前后端都拒绝空值和超长值，按普通文本渲染。
- [ ] 保存成功后当前页面、跨页及刷新一致；加载中、读取失败和保存失败分别提示，保存失败保留输入且不假报成功。
- [ ] 移除假团队和用户身份、P1/P6 阶段标签，显示“本机模式”；品牌保留 TestDock，名称、Logo、浏览器标题使用统一定义。
- [ ] 关于入口展示真实版本，提交标识不可用时明确说明；保持既有回环绑定和控制面保护。
- [ ] 隔离数据库验证持久化；浏览器验证改名、刷新及失败反馈，覆盖长中文名称和键盘操作。
