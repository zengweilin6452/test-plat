**What to build:** 让 Windows 使用者在常用窗口、缩放和辅助显示条件下可靠地完成现有关键操作。

## Acceptance criteria

- [x] 在隔离测试数据上分别触发弹层内真实成功和失败反馈，确认提示可见且不被弹层遮挡。
- [x] 验证抽屉一次关闭、Esc 关闭后重开、提交中关闭规则及焦点行为，避免一次点击叠开多层。
- [ ] 在目标 Windows 环境记录版本、架构、浏览器、窗口与缩放，检查 100%/125% 缩放、窗口调整和长名称。
- [ ] 使用键盘与鼠标完成关键流程，高对比度下焦点、状态和操作可辨认；检查适用浅色/深色条件，不新增主题系统。
- [x] 检查相关页面加载、失败、空态与部分缺失反馈；保留近期渐进式披露设计，不恢复旧首屏密度。
- [x] 保留关键状态截图与实际交互证据；无目标桌面环境时明确待验，不以构建、DOM 或静态测试代替视觉验收。
