# 08: Windows 部署、升级与恢复

**What to build:** 让部署者在独立 Windows 目录安装、启停与升级平台，并能从备份恢复历史数据和报告。

**Blocked by:** None (can start immediately)

**Status:** resolved

**规格依据：** TestDock 首个可交付版本收口规格；用户故事 4、27、28、29、30。

## Acceptance criteria

- [x] 在另一含空格目录及隔离数据库、产物目录完成正式初始化和完整启停；不依赖开发者原目录，不灌演示业务数据。
- [x] 健康检查识别本平台；端口冲突明确失败，停止只作用于本实例。
- [x] 以隔离旧库执行升级，保留稳定身份、历史运行、报告与证据；不改写历史迁移。
- [x] 备份并实际恢复隔离数据库与产物，核对恢复后的报告可读、证据可用及完整性；记录所用程序与数据库版本。
- [x] 升级或恢复失败时保留故障信息，使用隔离备份恢复测试环境，不覆盖用户现有业务数据。
- [x] 核对部署、升级与恢复说明可按实测操作执行；缺依赖或目标 Windows 条件时准确记录，不自行安装或更换依赖。
