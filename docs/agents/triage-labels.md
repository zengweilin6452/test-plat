# Triage 标签

工程技能使用五个规范分诊角色。本文件把它们映射到本仓库实际使用的标签字符串。

| 技能中的角色 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已完整定义，可交给代理执行 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不处理 |

技能提到某个角色时，使用本表对应的标签字符串。本地 Markdown tracker 用文件顶部的 `Status:` 行记录，而不是远程标签。
